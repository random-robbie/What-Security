cli tips

The commands I actually use day to day — searching, editing, text processing and general shell productivity. All examples are copy-paste ready.

$ searching for things

Search file contents with grep, file names with find. These two cover 90% of it.

# grep: search recursively, ignore case, show line numbers, colour output
grep -rni --colour=auto "password" ./src/

# only show the matching part, not the whole line (great for URLs/tokens)
grep -rhoE "https?://[a-zA-Z0-9./?=_-]+" ./logs/

# count matches per file, sorted by most hits
grep -rc "TODO" . | sort -t: -k2 -rn | head

# invert a match and exclude directories
grep -rn "error" ./app/ --exclude-dir=node_modules --exclude="*.min.js"

# find: files modified in the last 24 hours, larger than 10 MB
find . -type f -mtime -1 -size +10M

# find and run a command on each result (safe with spaces in names)
find . -name "*.log" -exec gzip {} \;

# find files by name, case-insensitive
find /etc -iname "*host*"

# locate anything fast (if your box has an up-to-date index)
locate -i id_rsa

$ search inside the terminal itself

# search your shell history as you type: press CTRL+R, then start typing
# press CTRL+R again to cycle through older matches

# search history without leaving the command line
history | grep ssh

# re-run the last command starting with "nmap"
!nmap

# search man pages: open a man page, then press / and type a keyword, n = next match
man nmap

$ editing files from the command line

# sed: replace text in place (backup first with -i.bak on macOS/BSD)
sed -i 's/http:/https:/g' config.txt

# sed: delete blank lines and comments
sed -E '/^\s*(#|$)/d' script.sh

# sed: strip ANSI colour codes from a log (the classic)
sed -E "s/[[:cntrl:]]\[[0-9]{1,3}m//g" tlog > newlog

# append a line to a file without opening an editor
echo "export PATH=$PATH:$HOME/bin" >> ~/.bashrc

# compare two files side by side, ignoring whitespace
diff -uw old.txt new.txt | less

# quick interactive editing when vim is overkill
nano +20 file.txt        # opens at line 20

# vim essentials: /search, n next match, :%s/old/new/g replace all, :wq save
vim +/"password" file.txt

$ text processing one-liners

# sort and deduplicate, counting occurrences (top talkers in a log)
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head

# cut out a field (second column of a colon-separated file)
cut -d: -f2 users.txt

# replace tabs with commas
expand -t 1 data.tsv | sed 's/\t/,/g' > data.csv

# word count, line count of everything you have typed today
history | wc -l

# watch a file grow in real time
tail -f /var/log/auth.log

# pretty-print JSON from an API
curl -s https://api.example.com/v1/thing | python3 -m json.tool

# jq: pull one field out of JSON
curl -s https://api.example.com/v1/users | jq '.[].email'

$ files and directories

# rsync: copy with progress, resumable, keeps permissions
rsync -avh --progress ./bigdir/ user@host:/backup/bigdir/

# find the 10 biggest directories under the current one
du -ah . | sort -rh | head -n 10

# free disk space summary, human readable
df -h

# create a nested path in one go
mkdir -p projects/{recon,exploits,reports}

# copy a file preserving ownership and permissions
cp -a /etc/nginx/nginx.conf /backup/

# securely shred a file before deleting it
shred -u secret.txt

$ permissions and ownership

# make a script executable
chmod +x enumerate.sh

# recursive ownership fix for a web root
sudo chown -R www-data:www-data /var/www/html

# find anything world-writable (a classic privilege-escalation check)
find / -writable -type f 2>/dev/null

# find SUID binaries
find / -perm -4000 -type f 2>/dev/null

$ networking quickies

# what is listening on my box
ss -tulpn

# quick DNS lookups
dig +short example.com A
dig +short -x 8.8.8.8      # reverse lookup

# grab headers only (server, CSP, cookies)
curl -sI https://example.com

# download a file with a sensible name and resume support
curl -LO -C - https://example.com/tool.tar.gz

# who owns this IP
whois 1.2.3.4 | grep -iE "orgname|country|netname"

$ shell productivity

# press TAB twice for suggestions; CTRL+L clears the screen
# CTRL+A / CTRL+E jump to start/end of the line, CTRL+W deletes a word

# run the previous command with sudo
sudo !!

# keep a command running after you log out
nohup ./long-job.sh &

# time any command precisely
time ./scan.sh

# run a command every 2 seconds and watch the output
watch -n 2 "ss -s"

# stop a job with CTRL+Z, then resume it in the background
bg
jobs
fg %1
